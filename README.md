## 📖 О проекте

**AccessEvent** — это веб-платформа, которая делает организацию и посещение мероприятий доступными для людей с нарушениями слуха. Вместо звуковых сигналов система использует **визуальные уведомления** (цветные баннеры), **текстовый чат** и **опции доступности** (сурдоперевод, субтитры, текстовая расшифровка).

Платформа объединяет **организаторов** и **участников**, предоставляя удобные инструменты для создания событий, регистрации, общения и обратной связи. Главный принцип AccessEvent: **никакая важная информация не должна передаваться только через звук**.

### 🎯 Ключевые особенности

- 🟡🟢🔴 **Визуальные уведомления** — цветные баннеры о статусе мероприятия вместо звуковых сигналов
- 💬 **Текстовый чат** — общение организатора и участников без необходимости слышать
- ♿ **Опции доступности** — сурдоперевод, субтитры, текстовая расшифровка, ассистивные технологии
- 📝 **Онлайн-регистрация** — с одобрением/отклонением заявок организатором
- ⭐ **Отзывы и рейтинги** — обратная связь после мероприятий
- 🎨 **WCAG 2.1 AA** — полное соответствие стандартам доступности
- 📱 **Mobile-first** — адаптивный дизайн для любых устройств
- 🔒 **Безопасность** — bcrypt-хеширование, защита от SQL-инъекций, CSRF-токены

## 🚀 Быстрый старт

### Предварительные требования

- **Python** 3.10+
- **PostgreSQL** 14+
- **Docker** и **Docker Compose** (опционально)
- **Git**

### Установка

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/your-org/accessevent.git
   cd accessevent
   ```

2. **Создайте виртуальное окружение:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/macOS
   venv\Scripts\activate     # Windows
   ```

3. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте переменные окружения:**
   ```bash
   cp .env.example .env
   ```
   Отредактируйте `.env`:
   ```env
   FLASK_APP=app.py
   FLASK_ENV=development
   SECRET_KEY=your-secret-key
   DATABASE_URL=postgresql://user:password@localhost:5432/accessevent
   BCRYPT_ROUNDS=12
   ```

5. **Инициализируйте базу данных:**
   ```bash
   flask db upgrade
   flask seed-db  # загрузка тестовых данных
   ```

6. **Запустите приложение:**
   ```bash
   flask run
   ```
   Откройте [http://localhost:5000](http://localhost:5000)

### 🐳 Запуск через Docker

```bash
docker-compose up --build
```

Приложение будет доступно на [http://localhost:5000](http://localhost:5000)

## 🔔 Визуальные уведомления

Ключевая особенность AccessEvent — цветовые баннеры вместо звуковых сигналов:

| Цвет | Значение | Когда отправляется |
|------|----------|-------------------|
| 🟡 **Жёлтый** | Скоро начало | За 30 минут до старта |
| 🟢 **Зелёный** | Мероприятие началось | В момент старта |
| 🔴 **Красный** | Отменено / перенесено | При изменении статуса |

Аналогично индицируется статус регистрации:
- ⚪ Серый — заявка на рассмотрении
- 🟢 Зелёный — одобрена
- 🔴 Красный — отклонена

## 🚢 Развёртывание

### CI/CD

Проект использует **GitHub Actions** для автоматической сборки и публикации Docker-образа в **GHCR**:

```yaml
# .github/workflows/deploy.yml
on:
  push:
    branches: [main]
```

### Production

```bash
# Сборка образа
docker build -t ghcr.io/your-org/accessevent:latest .

# Запуск через docker-compose
docker-compose -f docker-compose.prod.yml up -d
```

**Требования к production:**
- HTTPS (Let's Encrypt)
- PostgreSQL 14+ с ежедневным бэкапом (хранение ≥ 30 дней)
- Health-check эндпоинт `/health`
- Структурированные логи
- Мониторинг доступности
